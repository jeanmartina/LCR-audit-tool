# Phase 23 Plan 23-03: Worker Runtime Integration and Environment Controls

**Created:** 2026-05-01  
**Status:** Ready for execution

## Objective

Run policy-document monitoring in the existing worker process using conservative env-controlled cadence and limits, so Phase 23 is demonstrable end-to-end in the Docker topology.

## Scope

### In Scope

- Worker pass for discovered `policy-document` monitoring sources.
- In-process due scheduling with env-controlled interval.
- Integration into `scripts/run-worker.js`.
- `.env.example` and compose env wiring for Phase 23 runtime limits.
- Validator coverage for worker integration and env keys.

### Out of Scope

- OCSP source processing.
- New service/process.
- UI/reporting changes.
- Long-term distributed scheduling or horizontal worker coordination.

## Threat Model

<threat_model>
T-23-08: Worker failures for one source could stop the full monitoring loop. Mitigation: catch per-source errors, record failure events when possible, log cycle-level errors, and continue processing other sources.

T-23-09: Worker can hammer document URLs. Mitigation: `MONITORING_SOURCE_DOCUMENT_INTERVAL_SECONDS` defaults to `3600` and due checks are tracked in process by source ID.

T-23-10: Worker could accidentally process OCSP sources before Phase 24 semantics exist. Mitigation: filter to `sourceType === "policy-document"`, `state === "discovered"`, and non-null `sourceUrl`.
</threat_model>
