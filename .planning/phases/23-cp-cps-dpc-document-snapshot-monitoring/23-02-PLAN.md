# Phase 23 Plan 23-02: Document Snapshot Service and Text Extraction

**Created:** 2026-05-01  
**Status:** Ready for execution

## Objective

Implement the policy-document check service that fetches safe document URLs, records an event for every check, creates snapshots only when hashes change, extracts bounded text/metadata when feasible, and keeps raw evidence when extraction fails.

## Scope

### In Scope

- Evaluate PDF extraction dependency before selecting one.
- Add `src/monitoring-sources/documents.ts` document check service.
- Extract bounded text for `text/plain`, HTML, and PDFs where possible.
- Record `monitoring_source_events` for every check.
- Record `document_snapshots` only when the hash changes or no snapshot exists.
- Preserve raw bytes/hash/metadata even when extraction fails.

### Out of Scope

- Worker loop integration.
- Reporting UI.
- OCSP checks.
- AI compliance interpretation.

## Threat Model

<threat_model>
T-23-05: Malicious documents can contain active HTML or malformed PDF payloads. Mitigation: extract text only, never execute or render HTML, and treat extraction failure as data recorded on the snapshot rather than a fatal check failure.

T-23-06: PDF extraction dependency can add native or Docker-fragile runtime behavior. Mitigation: evaluate `pdfjs-dist` and `pdf-parse` with `npm view`, install the smallest build-safe dependency, and prove `npm run typecheck` and `npm run build` pass.

T-23-07: Repeated unchanged checks can duplicate raw content. Mitigation: compare SHA-256 with the latest snapshot and create a new snapshot only when no prior snapshot exists or the hash differs.
</threat_model>

<task id="23-02-T3" title="Implement policy document check and snapshot service">
  <read_first>
    - `src/monitoring-sources/documents.ts`
    - `src/monitoring-sources/fetch-safety.ts`
    - `src/storage/runtime-store.ts`
    - `src/monitoring-sources/types.ts`
  </read_first>
  <action>
    In `src/monitoring-sources/documents.ts`, export `checkPolicyDocumentSource(source: MonitoringSourceRecord): Promise<{ eventId: string; snapshotId: string | null; status: MonitoringSourceEventStatus; sha256: string | null }>`.

    Behavior:
    - If `source.sourceType !== "policy-document"`, record a `not_checkable` event with `failureReason: "source-not-policy-document"` and return without fetching.
    - If `source.state !== "discovered"` or `source.sourceUrl` is null, record a `not_checkable` event with `failureReason: "policy-document-source-not-discovered"` and return without fetching.
    - Call `fetchMonitoringSourceBytes(source.sourceUrl)`.
    - SHA-256 hash the raw `body` bytes.
    - Load `findLatestDocumentSnapshotForSource(source.id)`.
    - If no latest snapshot exists, create a snapshot and record event status `available`.
    - If latest snapshot `sha256` differs, create a snapshot and record event status `changed`.
    - If latest snapshot `sha256` is the same, do not create a snapshot and record event status `unchanged` linked to the latest snapshot ID.
    - If fetch safety throws `monitoring-source-url-private-address-blocked` or invalid-scheme errors, record event status `blocked`.
    - If byte limits throw `monitoring-source-document-too-large`, record event status `oversized`.
    - For other fetch failures, record event status `unavailable`.
    - If extraction returns `failed`, still create/link the snapshot and record event status `extraction_failed` with `failureReason` equal to the extraction failure reason.

    Snapshot creation must pass through `recordDocumentSnapshot` with `certificateId`, `fingerprint`, `policyOid`, `documentRole`, `trustListSourceId`, `trustListSnapshotId`, and `trustListRunId` copied from the source record.
  </action>
  <acceptance_criteria>
    - `src/monitoring-sources/documents.ts` exports `checkPolicyDocumentSource`.
    - `src/monitoring-sources/documents.ts` contains `findLatestDocumentSnapshotForSource`.
    - `src/monitoring-sources/documents.ts` contains `recordDocumentSnapshot`.
    - `src/monitoring-sources/documents.ts` contains `recordMonitoringSourceEvent`.
    - `src/monitoring-sources/documents.ts` contains `source-not-policy-document`.
    - `src/monitoring-sources/documents.ts` contains `policy-document-source-not-discovered`.
    - `src/monitoring-sources/documents.ts` contains `extraction_failed`.
    - `src/monitoring-sources/documents.ts` contains `changed`.
    - `src/monitoring-sources/documents.ts` contains `unchanged`.
  </acceptance_criteria>
</task>
