# Phase 22 Plan 22-03: Import Integration and Phase Validation Closure

**Created:** 2026-04-28  
**Status:** Ready for execution

## Objective

Integrate derived-source creation into certificate import and trust-list certificate projection flows, then close Phase 22 validators and full project validation.

## Scope

### In Scope

- Call derivation after successful certificate import/upsert.
- Upsert derived sources for single certificate, ZIP certificate, and trust-list-derived certificate flows.
- Pass trust-list provenance into source derivation when available.
- Ensure derivation errors do not fail import unless persistence itself fails.
- Close validators for schema, parser, call sites, deduplication, states, provenance, and no polling/fetching.

### Out of Scope

- Fetching policy documents.
- Polling OCSP responders.
- Reporting source status.

## Threat Model

- Derived-source creation must not silently mutate unrelated certificates.
- Trust-list provenance must be preserved without becoming part of the primary deduplication key.
- Import and sync flows must remain auditable even when derivation finds nothing or cannot parse extensions.
- No Phase 22 code should perform network fetches for OCSP or policy documents.
