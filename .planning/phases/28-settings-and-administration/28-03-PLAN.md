<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> provider save route | Untrusted form payloads can change provider enablement and verification. |
| browser -> administration summary | Audit and role data must be rendered as data, not executable content. |
| admin override -> provider runtime | A persisted enablement override must not silently erase the environment-configured callback identity. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-07 | E | `src/app/api/settings/platform/providers/[provider]/route.ts` | mitigate | Keep the route behind `assertPlatformAdmin()` and same-origin validation so only platform admins can alter provider runtime state. |
| T-28-08 | I | `src/settings/admin-overview.ts` | mitigate | Render audit and role records as plain text fields and never interpolate them into raw HTML. |
| T-28-09 | D | `src/auth/providers.ts` | accept | Provider enablement overrides only change whether a provider is exposed; they do not mutate provider secrets or the callback URL shape. |
</threat_model>
