## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> `/settings` GET | Untrusted query params choose the visible tab and saved notice state. |
| browser -> same-origin POST routes | Form submissions cross into authenticated server-side mutations. |
| field hint text -> UI primitives | Technical guidance must not become persistent explanatory copy or scriptable markup. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-01 | T | `src/app/settings/page.tsx` | mitigate | Parse only the known `tab` values and ignore everything else, so arbitrary query strings cannot steer the shell into an invalid state. |
| T-28-02 | I | `src/components/ui/primitives.tsx` | mitigate | Render hints as inert text-only hover affordances with `title={hint}` and keep all user-visible labels as React text, not HTML injection points. |
| T-28-03 | D | `src/app/setup/page.tsx` | accept | The setup completion link only navigates within the app; it does not change privileges or persist data. |
</threat_model>
