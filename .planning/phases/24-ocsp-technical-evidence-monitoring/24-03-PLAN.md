# Phase 24 Plan 24-03: OCSP Worker Integration and Runtime Controls

**Created:** 2026-05-04  
**Status:** Ready for execution

## Objective

Run OCSP technical checks in the existing worker process using a separate schedule and dedicated OCSP runtime limits.

## Scope

### In Scope

- Scheduled OCSP pass for due discovered `ocsp` sources.
- Integration into `scripts/run-worker.js` without adding services.
- `.env.example` and compose env wiring for OCSP limits.
- Operator docs for technical-only OCSP monitoring limits.
- Validator coverage for worker and env controls.

### Out of Scope

- Reporting UI.
- Full semantic OCSP validation.
- Manual OCSP source entry.

- `.planning/phases/24-ocsp-technical-evidence-monitoring/24-CONTEXT.md`

## Threat Model

<threat_model>
T-24-06: A single failing OCSP source could stop all worker cycles. Mitigation: catch per-source errors and cycle-level errors while continuing other sources.

T-24-07: OCSP checks can hammer responders if they reuse document cadence accidentally. Mitigation: dedicated `OCSP_CHECK_INTERVAL_SECONDS` schedule and module-level last-check map.
</threat_model>

<task id="24-03-T2" title="Wire OCSP checks into worker runtime">
  <read_first>
    - `scripts/run-worker.js`
    - `src/monitoring-sources/worker.ts`
  </read_first>
  <action>
    Modify `scripts/run-worker.js`.

    In `main()`, read:
    - `const runScheduledOcspSourceChecks = monitoringSources.runScheduledOcspSourceChecks;`

    Add an export check:
    - `throw new Error("runScheduledOcspSourceChecks export is required");`

    In the worker loop, call:

    ```js
    try {
      await runScheduledOcspSourceChecks();
    } catch (error) {
      const message = error instanceof Error ? error.stack ?? error.message : String(error);
      console.error(`[worker] ocsp source cycle failed: ${message}`);
    }
    ```

    Place the OCSP cycle after `await runScheduledDocumentSourceChecks();` and before sleep.
  </action>
  <acceptance_criteria>

    - `scripts/run-worker.js` contains `await runScheduledOcspSourceChecks();`.
    - `scripts/run-worker.js` contains `[worker] ocsp source cycle failed:`.
  </acceptance_criteria>
</task>
