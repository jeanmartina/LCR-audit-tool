| T-34-02 | I | `src/app/api/version/route.ts` payload | mitigate | Return minimal read-only payload from shared resolver; no secrets or extended metadata fields. |
| T-34-03 | T | UI/API contract drift | mitigate | Use single resolver (`src/lib/runtime-version.ts`) consumed by both layout and API; add validator anchors for both links. |
| T-34-04 | R | packaged-runtime verification ambiguity | mitigate | Document deterministic operator verification steps and validate route/layout anchors in automation. |
</threat_model>
