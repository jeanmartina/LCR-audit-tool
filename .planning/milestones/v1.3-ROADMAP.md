# Milestone v1.3: Monitoring Source Expansion

**Status:** ✅ SHIPPED 2026-05-09
**Phases:** 22-26
**Total Plans:** 13

## Overview

v1.3 expanded the monitoring runtime beyond CRL and certificate coverage into derived OCSP responders and CP/CPS/DPC policy-document evidence, then closed the packaged runtime with explicit operational limits, safety controls, and proof artifacts for future PKI analysis.

## Phases

**Goal**: Add a deterministic derived-source layer for OCSP and policy-document candidates tied to existing certificates and trust-list provenance.
**Depends on**: Phase 21.1
**Plans**: 3 plans

Plans:

- [x] 22-01: Monitoring source storage and identity model

## Milestone Summary

**Key Decisions:**

- Keep derived-source runtime limits explicit in both the canonical environment template and packaged compose wiring.
- Treat technical evidence retention and the future AI-assisted PKI policy-analysis boundary as a documented closure boundary, not a delivered feature.
- Close the milestone only after validator, docs, typecheck, and production build checks pass.

**Issues Resolved:**

- Derived OCSP and policy-document source discovery shipped on top of the existing certificate-first import path.
- Safe policy-document fetching and snapshotting shipped with bounded extraction and provenance retention.
- OCSP technical evidence shipped with issuer-context gating and non-semantic health labels.
- Reporting now exposes derived-source health under the existing authorization model.
- The packaged stack now exposes runtime safety limits and closure proof artifacts explicitly.

**Issues Deferred:**

- Full OCSP semantic validation remains future scope.
- AI-assisted PKI policy analysis remains future scope.
- Manual OCSP/document source entry remains future scope.
- Advanced SLO/burn-rate analytics for derived sources remain future scope.

**Technical Debt Incurred:**

- Rotate the Google client secret used during proof because it was exposed during testing.
- The workspace root emits a Next.js multiple-lockfile warning; the build passes, but the workspace layout should be cleaned up later.
