# v1.4 Deploy + UAT Plan (Server)

## Objective
Deploy the exact v1.4 build to server and close deferred human-UAT debt from phases 31-34 with runtime evidence.

## Scope
- Deploy only (no feature edits).
- Validate human-UAT items from:
  - `31-HUMAN-UAT.md`
  - `32-HUMAN-UAT.md`
  - `33-HUMAN-UAT.md`
  - `34-HUMAN-UAT.md`

## Pre-deploy Checklist
1. Confirm branch/tag to deploy: `v1.4`.
2. Backup runtime env and database snapshot.
3. Confirm production env vars include `APP_VERSION`.
4. Confirm compose stack health before change (`web`, `worker`, `postgres`, `caddy`).

## Deploy Steps
1. Checkout release tag: `git checkout v1.4`.
2. Build/update containers.
3. Restart compose stack.
4. Verify app boot, auth route, dashboard load, and worker polls.

## UAT Closure Matrix

### Phase 31 (Dashboard/Reporting)
- Execute each step in `31-HUMAN-UAT.md` on server runtime.
- Collect screenshots and endpoint responses.
- Record PASS/FAIL with timestamp.

### Phase 32 (Executive PDF)
- Generate PDF from live runtime data.
- Validate Unicode/sections/layout against checklist in `32-HUMAN-UAT.md`.
- Attach sample PDF artifacts.

### Phase 33 (Global UX)
- Walk major routes (`/`, `/auth`, reporting, settings, admin).
- Validate consistency checklist in `33-HUMAN-UAT.md`.
- Record visual evidence.

### Phase 34 (Release Clarity)
- Confirm topbar `vX.Y.Z` and `/api/version` parity.
- Confirm missing/invalid metadata fallback behavior.
- Record evidence per `34-HUMAN-UAT.md`.

## Evidence Capture
- Save screenshots + terminal outputs under a dated folder (for example `ops/uat/v1.4-YYYY-MM-DD/`).
- Update each phase HUMAN-UAT file with result notes.
- If all PASS, update corresponding `*-VERIFICATION.md` status notes to reflect human verification completed.

## Exit Criteria
- Deploy stable on server.
- All 4 HUMAN-UAT files marked completed with evidence.
- Final re-audit (`/gsd-audit-milestone`) remains `passed` or `tech_debt` with no unresolved human-UAT items.
